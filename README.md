# Galaxy Client

🌌 **Futuristic Fabric Minecraft Client** 🌌

A powerful and customizable Fabric mod for Minecraft 1.21.1 with advanced features like Combat Systems, Automation, and a sleek ClickGUI.

## Features

✦ **Futuristic GUI**
- Tabbed ClickGUI with Galaxy-themed interface
- Smooth animations and modern design

◈ **Combat System**
- Auto-hit functionality
- Critical strike enhancement
- Extended reach distance
- Targeting ESP

⬡ **Automation**
- Auto-fishing
- Auto-mining
- Customizable automation modules

## Requirements

- Minecraft 1.21.1
- Fabric Loader
- Java 21+

## Installation

1. Download the latest release from [Releases](https://github.com/anrchaw9ds/galaxy-client/releases)
2. Place the JAR file in your `.minecraft/mods` folder
3. Launch Minecraft with Fabric
4. Press **Left Alt** to open the ClickGUI

## Building from Source

```bash
# Clone the repository
git clone https://github.com/anrchaw9ds/galaxy-client.git
cd galaxy-client

# Build the mod
./gradlew build

# Output JAR will be in build/libs/
```

## Usage

- **Default ClickGUI Key**: Left Alt
- Toggle modules on/off in the GUI
- Customize module settings as needed

## Configuration

Module settings are managed through the ClickGUI. More advanced configuration will be added in future releases.
